# 02 · Cups Calculator

**Topic:** Integer division and remainder

Complete calculateCups(int numberOfCups). Each box holds 3 cups. For a supplied count in 0…1000000, print the number of full boxes and cups left unpacked. Tests supply the parameter, so do not add main or input reading.

Use straight-line local declarations and expression statements, without branches or loops. End each output line with println.

## Requirements

- Use only int local variables, arithmetic and System.out.println in the method body; no other method calls, arrays, objects, branches or loops.

numberOfCups = 10.
