# 02 · Puodelių pakavimas

**Tema:** Sveikųjų skaičių dalyba ir liekana

Užpildykite calculateCups(int numberOfCups). Dėžėje telpa 3 puodeliai. Kai pateiktas skaičius yra 0…1000000, išveskite pilnų dėžių ir nesupakuotų puodelių skaičių. Parametrą perduoda testai, todėl main ir įvesties skaitymo nepridėkite.

Naudokite nuoseklius lokalių kintamųjų deklaravimo ir išraiškų sakinius be šakų ar ciklų. Kiekvieną išvedimo eilutę užbaikite println.

## Reikalavimai

- Metodo kūne naudokite tik int lokalius kintamuosius, aritmetiką ir System.out.println; be kitų metodų iškvietimų, masyvų, objektų, šakų ir ciklų.

numberOfCups = 10.

```console
Dėžių: 3
Liko puodelių: 1
```
