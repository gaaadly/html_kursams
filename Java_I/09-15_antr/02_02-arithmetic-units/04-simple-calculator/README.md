# 04 · Simple Calculator

**Topic:** Arithmetic operators

Ask for two whole numbers in −1000…1000. The second is not zero. Print their sum, difference, product and quotient as four equations in that order. The quotient must be a real number. Print each prompt before reading and preserve the spaces shown.

Use straight-line local declarations and expression statements, without branches or loops. End each output line with println.

## Requirements

- Read int first and int second using nextLine and Integer.parseInt.

Typed values: `9`, `2`.

```console
Give the first number:
9
Give the second number:
2
9 + 2 = 11
9 - 2 = 7
9 * 2 = 18
9 / 2 = 4.5
```
