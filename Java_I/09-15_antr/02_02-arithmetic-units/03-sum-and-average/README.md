# 03 · Sum and Average

**Topic:** Arithmetic and real division

Ask for three integers in −1000…1000 and print their sum and average. Print each prompt before reading and both results after all inputs. Keep the fractional part of the average.

Use straight-line local declarations and expression statements, without branches or loops. End each output line with println.

## Requirements

- Read with nextLine and Integer.parseInt. Calculate int sum, then compute double average from sum and use both variables in output.

Typed values: `8`, `2`, `3`.

```console
Give the first number:
8
Give the second number:
2
Give the third number:
3
The sum of the numbers is 13
The average is 4.333333333333333
```

Typed values: `1`, `2`, `3`.

```console
Give the first number:
1
Give the second number:
2
Give the third number:
3
The sum of the numbers is 6
The average is 2.0
```
