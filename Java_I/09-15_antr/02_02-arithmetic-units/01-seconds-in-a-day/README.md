# 01 · Seconds in a Day

**Topic:** Constants and arithmetic

Ask for a whole number of days in 0…1000000 and print the number of seconds. A day has 24 hours, an hour 60 minutes and a minute 60 seconds. Calculate with long arithmetic so large results remain correct.

Use straight-line local declarations and expression statements, without branches or loops. End each output line with println.

## Requirements

- Read int days using nextLine and Integer.parseInt. Declare and use final long HOURS_PER_DAY = 24L, final int MINUTES_PER_HOUR = 60 and final int SECONDS_PER_MINUTE = 60. Store the result in long seconds.

Typed values: `30000`.

```console
How many days would you like to convert to seconds?
30000
2592000000
```
