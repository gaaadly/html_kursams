# 05 · Mylios į kilometrus (papildomai)

**Tema:** Vienetų konversija

Paprašykite realiojo mylių skaičiaus intervale 0…1000 ir išveskite kilometrus. Naudokite užduoties prielaidą: viena mylia lygi 1.6 kilometro. Tai papildoma programavimo užduotis.

Naudokite nuoseklius lokalių kintamųjų deklaravimo ir išraiškų sakinius be šakų ar ciklų. Kiekvieną išvedimo eilutę užbaikite println.

## Reikalavimai

- Su nextLine ir Double.parseDouble perskaitykite double miles. Deklaruokite ir naudokite final double KILOMETERS_PER_MILE = 1.6.

Įvedamos reikšmės: `2.5`.

```console
Enter miles:
2.5
Kilometers: 4.0
```
