# 05 · Miles to Kilometers (Optional)

**Topic:** Unit conversion

Ask for a decimal number of miles in 0…1000 and print kilometers. Use the exercise assumption that one mile equals 1.6 kilometers. This is an optional additional programming task.

Use straight-line local declarations and expression statements, without branches or loops. End each output line with println.

## Requirements

- Read double miles using nextLine and Double.parseDouble. Declare and use final double KILOMETERS_PER_MILE = 1.6.

Typed values: `2.5`.

```console
Enter miles:
2.5
Kilometers: 4.0
```
