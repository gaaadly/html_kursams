# 03 · Sveikojo ir realiojo skaičiaus įvestis

**Tema:** Skaitinė įvestis

Paprašykite programos išeities eilučių skaičiaus ir vykdymo laiko milisekundėmis, abu intervale −1000…1000. Kiekvieną kvietimą išveskite prieš skaitydami eilutę, tada išveskite abi konvertuotas reikšmes. Trupmenai naudojamas taškas; 3.140 išvedamas kaip reikšmė 3.14. Netinkamas skaitinis tekstas gali nutraukti programą su NumberFormatException; klaidų apdorojimo nereikia.

Naudokite nuoseklius lokalių kintamųjų deklaravimo ir išraiškų sakinius be šakų ar ciklų. Kiekvieną išvedimo eilutę užbaikite println.

## Reikalavimai

- Naudokite nextLine, Integer.parseInt ir Double.parseDouble; reikšmes išsaugokite int sourceLines ir double executionTimeMillis.

Įvedamos reikšmės: `8`, `3.140`.

```console
Give source line count:
8
Give execution time in milliseconds:
3.140
Source line count: 8
Execution time (ms): 3.14
```
