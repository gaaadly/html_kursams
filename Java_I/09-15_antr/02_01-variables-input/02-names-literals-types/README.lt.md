# 02 · Literalai ir reikšmės keitimas

**Tema:** Literalai ir tipo nustatymas

Programa veikia, bet jos reikšmės klaidingos. Pataisykite, kad ji išvestų didžiausią nepasirašytą int reikšmę 2147483648, podėlio santykį 0.5, baitų mastelį 2560.0 ir disko raidę C. Išveskite Java, pakeiskite tą patį language kintamąjį į Java 25 ir vėl išveskite.

Naudokite nuoseklius lokalių kintamųjų deklaravimo ir išraiškų sakinius be šakų ar ciklų. Kiekvieną išvedimo eilutę užbaikite println.

## Reikalavimai

- Palikite long maxUnsignedInt, float cacheRatio, double byteScale, char driveLetter ir var language, naudokite juos išvedimui. Naudokite long literalą su L, float literalą su F ir eksponentinį byteScale užrašą. language keiskite priskyrimu, ne antru deklaravimu.

```console
Max unsigned int: 2147483648
Cache ratio: 0.5
Byte scale: 2560.0
Drive letter: C
Before: Java
After: Java 25
```
