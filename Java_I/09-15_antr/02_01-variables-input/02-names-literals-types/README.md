# 02 · Literals and Reassignment

**Topic:** Literals and type inference

The program runs but contains incorrect values. Fix it to print the maximum unsigned int 2147483648, cache ratio 0.5, byte scale 2560.0 and drive letter C. Print Java, change the same language variable to Java 25, and print it again.

Use straight-line local declarations and expression statements, without branches or loops. End each output line with println.

## Requirements

- Keep long maxUnsignedInt, float cacheRatio, double byteScale, char driveLetter and var language, and use them in output. Use a long literal with L, a float literal with F and exponent notation for byteScale. Change language with an assignment, not a second declaration.

```console
Max unsigned int: 2147483648
Cache ratio: 0.5
Byte scale: 2560.0
Drive letter: C
Before: Java
After: Java 25
```
