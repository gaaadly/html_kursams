# 01 · Various Variables

**Topic:** Variables and assignment

Change the supplied byte count to 9000, CPU load to 0.1 and compiler name to javac. Keep the existing output layout. Then print a module count before and after changing it from 4 to 6, followed by the drive letter C, compilation status true, developer Ada and the path shown below. The program reads no input.

Use straight-line local declarations and expression statements, without branches or loops. End each output line with println.

## Requirements

- Declare int modules without an initializer, then assign 4 and 6 separately to that same variable. Use char driveLetter, boolean compiled and String developer for the added values and output. Keep the original int byteCount, double cpuLoad and String compiler.

```console
Bytes:
9000

0.1
Compiler:
javac

And finally, a summary:
9000
0.1
javac
Modules before: 4
Modules after: 6
Drive letter: C
Compiled: true
Developer: Ada
Path: C:\Java
```
