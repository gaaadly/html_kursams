# 01 · Įvairūs kintamieji

**Tema:** Kintamieji ir priskyrimas

Pakeiskite pateiktą baitų skaičių į 9000, procesoriaus apkrovą į 0.1, kompiliatoriaus pavadinimą į javac. Išlaikykite esamą išvedimo išdėstymą. Tada išveskite modulių skaičių prieš ir po pakeitimo iš 4 į 6, disko raidę C, kompiliavimo būseną true, kūrėją Ada ir pavyzdžio kelią. Programa įvesties neskaito.

Naudokite nuoseklius lokalių kintamųjų deklaravimo ir išraiškų sakinius be šakų ar ciklų. Kiekvieną išvedimo eilutę užbaikite println.

## Reikalavimai

- Deklaruokite int modules be pradinės reikšmės, tada tam pačiam kintamajam atskirai priskirkite 4 ir 6. Pridėtoms reikšmėms ir išvedimui naudokite char driveLetter, boolean compiled ir String developer. Palikite pradinius int byteCount, double cpuLoad ir String compiler.

```console
Bytes:
9000
CPU load:
0.1
Compiler:
javac

And finally, a summary:
9000
0.1
javac
Modules before: 4
Modules after: 6
Drive letter: C
Compiled: true
Developer: Ada
Path: C:\Java
```
