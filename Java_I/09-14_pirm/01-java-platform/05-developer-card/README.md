# 05 · Developer Card

**Topic:** Input/output sequencing

Complete `DeveloperCard.java`. Keep the opening line, ask for a name, and read the complete answer into a `String` variable named `name`. Then ask what the user wants to build and read the complete answer into a `String` variable named `goal`. Print the card only after both answers have been read. The values after the prompts are typed by the user.

```console
Let's create your developer card.
What is your name?
› Ada
What do you want to build?
› an accessibility tool
Developer card:
Name: Ada
Goal: an accessibility tool
Java version: 25
```
