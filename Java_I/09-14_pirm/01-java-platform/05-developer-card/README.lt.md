# 05 · Programuotojo kortelė

**Tema:** Įvesties ir išvesties seka

Užbaikite `DeveloperCard.java`. Palikite pirmąją eilutę, paklauskite vardo ir perskaitykite visą atsakymą į `String` kintamąjį vardu `name`. Tada paklauskite, ką naudotojas nori sukurti, ir perskaitykite visą atsakymą į `String` kintamąjį vardu `goal`. Kortelę išveskite tik perskaitę abu atsakymus. Reikšmes po klausimų įveda naudotojas.

```console
Let's create your developer card.
What is your name?
› Ada
What do you want to build?
› an accessibility tool
Developer card:
Name: Ada
Goal: an accessibility tool
Java version: 25
```
