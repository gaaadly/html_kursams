# 04 · Course Greeting

**Topic:** Variables and string concatenation

Complete `CourseGreeting.java`. The program asks for the student's name, reads the complete line into a `String` variable named `name`, and joins that value with fixed text to print a greeting. The values after the prompts are typed by the user.

```console
What is your name?
› Maya
Welcome to the Java course, Maya!
```

```console
What is your name?
› Alex Kim
Welcome to the Java course, Alex Kim!
```
