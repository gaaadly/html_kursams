# 04 · Kurso pasisveikinimas

**Tema:** Kintamieji ir teksto jungimas

Užbaikite `CourseGreeting.java`. Programa paklausia studento vardo, perskaito visą eilutę į `String` kintamąjį vardu `name` ir sujungia šią reikšmę su pastoviu tekstu, kad išvestų pasisveikinimą. Reikšmes po klausimų įveda naudotojas.

```console
What is your name?
› Maya
Welcome to the Java course, Maya!
```

```console
What is your name?
› Alex Kim
Welcome to the Java course, Alex Kim!
```
