# 03 · Echo Message

**Topic:** Console input with `Scanner`

Complete `EchoMessage.java`. The program asks for a message, reads one complete line, stores it in a `String` variable named `message`, and prints the same message. The values after the prompts are typed by the user.

```console
Enter a message:
› Hello!
Hello!
```

```console
Enter a message:
› Learning Java one step at a time.
Learning Java one step at a time.
```
