# 03 · Žinutės pakartojimas

**Tema:** Įvestis iš konsolės su `Scanner`

Užbaikite `EchoMessage.java`. Programa paprašo įvesti žinutę, perskaito vieną visą eilutę, išsaugo ją `String` kintamajame vardu `message` ir išveda tą pačią žinutę. Reikšmes po klausimų įveda naudotojas.

```console
Enter a message:
› Hello!
Hello!
```

```console
Enter a message:
› Learning Java one step at a time.
Learning Java one step at a time.
```
