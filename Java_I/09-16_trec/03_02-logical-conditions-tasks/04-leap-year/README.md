# 04 · Leap Year

**Topic:** Combined logical conditions

Ask for a year. A year is a leap year when it is divisible by 400, or when it is divisible by 4 but not by 100. Print exactly one of the two result messages shown below.

## Requirements

- Store the rule in a boolean expression using `||` and `&&`.

Values entered after prompts are typed by the user.

```console
Give a year:
2012
The year is a leap year.
```

```console
Give a year:
1800
The year is not a leap year.
```

```console
Give a year:
2000
The year is a leap year.
```
