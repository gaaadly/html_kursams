# 04 · Keliamieji metai

**Tema:** Sudėtinės loginės sąlygos

Paprašykite įvesti metus. Metai yra keliamieji, jei dalijasi iš 400 arba jei dalijasi iš 4, bet nesidalija iš 100. Išveskite lygiai vieną iš dviejų žemiau parodytų rezultato pranešimų.

## Reikalavimai

- Taisyklę saugokite loginėje išraiškoje, naudodami `||` ir `&&`.

Reikšmes po kvietimų įveda naudotojas.

```console
Give a year:
2012
The year is a leap year.
```

```console
Give a year:
1800
The year is not a leap year.
```

```console
Give a year:
2000
The year is a leap year.
```
