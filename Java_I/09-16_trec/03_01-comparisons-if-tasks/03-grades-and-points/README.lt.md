# 03 · Pažymiai ir taškai

**Tema:** Surikiuotos else-if ribos

Paprašykite įvesti taškų skaičių sveikuoju skaičiumi ir išveskite įvertinimą. Mažiau nei 0 yra `impossible!`; 0-49 - `failed`; 50-59 - `1`; 60-69 - `2`; 70-79 - `3`; 80-89 - `4`; 90-100 - `5`; daugiau nei 100 - `incredible!`. Konkretesnę aukštą ribą tikrinkite prieš platesnes žemesnes ribas.

## Reikalavimai

- Naudokite vieną surikiuotą `if` / `else if` / `else` grandinę.

Reikšmes po kvietimų įveda naudotojas.

```console
Give points:
49
Grade: failed
```

```console
Give points:
100
Grade: 5
```

```console
Give points:
101
Grade: incredible!
```
