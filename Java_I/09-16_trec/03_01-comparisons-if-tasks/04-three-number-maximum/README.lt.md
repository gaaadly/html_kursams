# 04 · Didžiausias iš trijų

**Tema:** Nepriklausomi if sakiniai

Paprašykite įvesti tris sveikuosius skaičius ir išveskite didžiausią reikšmę. Pradinę didžiausią reikšmę nustatykite pagal pirmą skaičių, tada antrą ir trečią skaičius palyginkite dviem nepriklausomais `if` sakiniais su figūriniais skliaustais. Nenaudokite `else`, `Math.max`, masyvų ar ciklų.

## Reikalavimai

- Naudokite lygiai du nepriklausomus aukščiausio lygio `if` sakinius.

Reikšmes po kvietimų įveda naudotojas.

```console
Give the first number:
10
Give the second number:
15
Give the third number:
5
Maximum: 15
```

```console
Give the first number:
-4
Give the second number:
-9
Give the third number:
-2
Maximum: -2
```
