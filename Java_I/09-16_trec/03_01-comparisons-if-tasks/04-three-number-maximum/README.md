# 04 · Three-number Maximum

**Topic:** Independent if statements

Ask for three whole numbers and print the greatest value. Start the maximum with the first value, then compare the second and third values in two independent braced `if` statements. Do not use `else`, `Math.max`, arrays, or loops.

## Requirements

- Use exactly two independent top-level `if` statements.

Values entered after prompts are typed by the user.

```console
Give the first number:
10
Give the second number:
15
Give the third number:
5
Maximum: 15
```

```console
Give the first number:
-4
Give the second number:
-9
Give the third number:
-2
Maximum: -2
```
