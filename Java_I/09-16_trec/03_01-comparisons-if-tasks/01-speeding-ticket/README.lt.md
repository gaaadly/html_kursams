# 01 · Greičio viršijimas

**Tema:** Palyginimas ir vienas if

Paprašykite įvesti greitį sveikuoju skaičiumi. `Speeding ticket!` išveskite tik tada, kai greitis didesnis už 120. Įvedus 120 ar mažiau, po kvietimo daugiau nieko neišveskite. Naudokite `if` bloką su figūriniais skliaustais.

## Reikalavimai

- Naudokite `>` ir vieną `if` sakinį su figūriniais skliaustais.

Reikšmes po kvietimų įveda naudotojas.

```console
Give speed:
119
```

```console
Give speed:
135
Speeding ticket!
```
