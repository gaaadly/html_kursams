# 01 · Speeding Ticket

**Topic:** Comparison and a single if

Ask for a whole-number speed. Print `Speeding ticket!` only when the speed is greater than 120. At 120 or below, print no message after the prompt. Use a braced `if` block.

## Requirements

- Use `>` and one braced `if` statement.

Values entered after prompts are typed by the user.

```console
Give speed:
119
```

```console
Give speed:
135
Speeding ticket!
```
