# 02 · Larger or Equal

**Topic:** if, else if and else

Ask for two whole numbers. If they are equal, print `The numbers are equal.` Otherwise print the larger number. Print each prompt before reading its value.

Values entered after prompts are typed by the user.

```console
Give the first number:
5
Give the second number:
8
Larger number: 8
```

```console
Give the first number:
-3
Give the second number:
-3
The numbers are equal.
```
