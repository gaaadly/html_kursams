# 02 · Didesnis arba lygūs

**Tema:** if, else if ir else

Paprašykite įvesti du sveikuosius skaičius. Jei jie lygūs, išveskite `The numbers are equal.` Kitu atveju išveskite didesnį skaičių. Kiekvieną kvietimą išveskite prieš nuskaitydami reikšmę.

Reikšmes po kvietimų įveda naudotojas.

```console
Give the first number:
5
Give the second number:
8
Larger number: 8
```

```console
Give the first number:
-3
Give the second number:
-3
The numbers are equal.
```
