# 01 · Carry On

**Topic:** while and break

Write a program that repeatedly prints `Shall we carry on?` and reads a line. Stop only when the user enters exactly `no`. The question must also be printed before the final `no`.

## Requirements

- Use a `while` loop and an unlabeled `break`.

Values entered after prompts are typed by the user.

```console
Shall we carry on?
yes
Shall we carry on?
no
```

```console
Shall we carry on?
no
```
