# 01 · Ar tęsti?

**Tema:** while ir break

Parašykite programą, kuri kartotinai išveda `Shall we carry on?` ir nuskaito eilutę. Sustokite tik tada, kai naudotojas įveda tiksliai `no`. Klausimas turi būti išvestas ir prieš galutinį `no`.

## Reikalavimai

- Naudokite `while` ciklą ir nežymėtą `break`.

Po kvietimų parodytas reikšmes įveda naudotojas.

```console
Shall we carry on?
yes
Shall we carry on?
no
```

```console
Shall we carry on?
no
```
