# 02 · Iki keturių

**Tema:** do-while

Parašykite programą, kuri išveda `Give a number:`, nuskaito sveikąjį skaičių ir kartoja, kol naudotojas įveda `4`. Kvietimas ir nuskaitymas turi įvykti bent vieną kartą.

## Reikalavimai

- Naudokite `do-while` ciklą.

Po kvietimų parodytas reikšmes įveda naudotojas.

```console
Give a number:
5
Give a number:
4
```

```console
Give a number:
4
```
