# 02 · Until Four

**Topic:** do-while

Write a program that prints `Give a number:`, reads a whole number, and repeats until the user enters `4`. The prompt and read must happen at least once.

## Requirements

- Use a `do-while` loop.

Values entered after prompts are typed by the user.

```console
Give a number:
5
Give a number:
4
```

```console
Give a number:
4
```
