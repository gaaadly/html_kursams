# 03 · Teigiamų skaičių kvadratai

**Tema:** while, break ir continue

Kartotinai išveskite `Give a number:` ir nuskaitykite sveikąjį skaičių. Įvedus `0`, sustokite. Neigiamam skaičiui išveskite `Unsuitable number` ir pereikite prie kitos įvesties. Teigiamam skaičiui išveskite jo kvadratą.

## Reikalavimai

- Naudokite vieną `while` ciklą, `break` nuliui ir `continue` po neigiamos reikšmės.

Po kvietimų parodytas reikšmes įveda naudotojas.

```console
Give a number:
5
25
Give a number:
-3
Unsuitable number
Give a number:
0
```
