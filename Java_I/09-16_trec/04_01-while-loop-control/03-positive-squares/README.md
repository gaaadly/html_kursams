# 03 · Positive Squares

**Topic:** while, break and continue

Repeatedly print `Give a number:` and read a whole number. Stop on `0`. For a negative number print `Unsuitable number` and continue with the next input. For a positive number print its square.

## Requirements

- Use one `while` loop, `break` for zero, and `continue` after a negative value.

Values entered after prompts are typed by the user.

```console
Give a number:
5
25
Give a number:
-3
Unsuitable number
Give a number:
0
```
