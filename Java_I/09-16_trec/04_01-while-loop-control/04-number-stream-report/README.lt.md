# 04 · Skaičių srauto ataskaita

**Tema:** Ciklas su baigimo reikšme ir kaupikliai

Kartotinai išveskite `Give a number:` ir skaitykite sveikuosius skaičius iki `0`. Nulio neįtraukite. Tada parodyta tvarka išveskite skaičių kiekį, sumą, vidurkį, neigiamų skaičių kiekį, maksimumą, teigiamų skaičių vidurkį, lyginių ir nelyginių skaičių kiekius. Jei vidurkio ar maksimumo apskaičiuoti negalima, išveskite parodytą tekstą.

## Reikalavimai

- Naudokite `while` ciklą ir nežymėtą `break`. Ataskaitą skaičiuokite skaitydami; nekaupkite visų įvestų reikšmių.

Po kvietimų parodytas reikšmes įveda naudotojas.

```console
Give a number:
5
Give a number:
2
Give a number:
-3
Give a number:
0
Numbers: 3
Sum: 4
Average: 1.3333333333333333
Negative: 1
Maximum: 5
Positive average: 3.5
Even: 1
Odd: 2
```

```console
Give a number:
0
Numbers: 0
Sum: 0
Average: cannot calculate
Negative: 0
Maximum: no numbers
Positive average: cannot calculate
Even: 0
Odd: 0
```
